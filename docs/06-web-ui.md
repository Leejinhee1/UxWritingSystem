# 웹 UI 화면 설계

## 앱 구조

하나의 Next.js 앱, 세 개의 탭.

```
┌───────────────────────────────────────────────────────────┐
│  UX Writing System    [UX Writing System] [테스트] [관리]  │
├───────────────────────────────────────────────────────────┤
│                                                           │
│  탭 1: UX Writing System — 라이팅 규칙 조회 (사이드바)     │
│  탭 2: 테스트 — Figma 플러그인 전 감사 엔진 검증            │
│  탭 3: 관리 — 규칙 데이터 CRUD (비밀번호 보호)              │
│                                                           │
└───────────────────────────────────────────────────────────┘
```

| 탭 | URL | 목적 | 접근 |
|----|-----|------|------|
| UX Writing System | `/`, `/voice`, `/tone` 등 | 라이팅 규칙 조회. 팀 공유용. | 누구나 |
| 테스트 | `/test`, `/test/history` | Figma 플러그인 전 감사 엔진 검증 | 누구나 |
| 관리 | `/admin/*` | 규칙 데이터 CRUD | 비밀번호 |

## 페이지 구조

```
탭 1 — UX Writing System (규칙 조회, 누구나):
/                        → 개요
/voice                   → Layer 1: Voice
/principles              → Layer 2: Writing Principles
/grammar                 → Layer 3: Grammar & Mechanics
/patterns                → Layer 4: Component Patterns (톤 포함)
/patterns/[ui_type]      → 컴포넌트별 상세 (버튼, 에러 등)
/wordlist                → Layer 5: Word List

탭 2 — 테스트 (Figma 플러그인 전 검증):
/test                    → 문구 테스트 (단일 + 일괄)
/test/history            → 테스트 히스토리

탭 3 — 관리 (데이터 CRUD, 비밀번호 보호):
/admin                   → 비밀번호 입력 (미인증 시)
/admin/voice             → Voice 편집
/admin/principles        → Writing Principles 편집
/admin/grammar           → Grammar 편집
/admin/patterns          → Component Patterns 편집
/admin/wordlist          → Word List 편집 (aliases 관리)
```

## 탭 3: 관리 상세

규칙 데이터 CRUD. 비밀번호로 접근 보호.

### 비밀번호 입력 (`/admin`)

미인증 상태에서 "관리" 탭 클릭 시 표시.

```
┌─────────────────────────────────────────┐
│                                         │
│              관리자 인증                  │
│                                         │
│     비밀번호를 입력하세요                  │
│     ┌─────────────────────┐             │
│     │ ••••••••            │             │
│     └─────────────────────┘             │
│              [ 확인 ]                    │
│                                         │
└─────────────────────────────────────────┘
```

- 환경변수 `ADMIN_PASSWORD`와 비교
- 인증 성공 → 세션 쿠키 발급 → `/admin/voice`로 리다이렉트
- 브라우저 닫으면 세션 초기화

## 비밀번호 보호 구현

- `ADMIN_PASSWORD` 환경변수에 비밀번호 저장
- `POST /api/auth` → 비밀번호 검증 → httpOnly 세션 쿠키 발급
- "관리" 탭 클릭 시 세션 없으면 비밀번호 입력 화면
- 편집 API (POST/PUT/DELETE /api/rules/*) → 세션 쿠키 검증, 없으면 403
- 조회 API (GET) → 인증 불요
- 브라우저 닫으면 세션 초기화
